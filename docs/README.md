# Documentação do Hiraishin-Z80

## Proposta

- `proposta.pdf`: arquivo pronto para envio.
- `proposta.tex`: fonte editável.
- `respostas.txt`: registro das respostas e decisões dos campos.
- Figuras utilizadas na proposta.

## Arquitetura

- `arquitetura/guia-arquitetura.html`: campo 4, mapas, decodificação e decisões do núcleo.
- `arquitetura/diagrama-minimo.svg`: diagrama atual do núcleo mínimo.

## Estudo

Materiais explicativos para compreender e defender a arquitetura, o bootloader e o sistema operacional. Alguns exemplos iniciais foram mantidos como histórico e identificados dentro das próprias páginas.

## Componentes

A [referência de componentes e compras](componentes/README.md) aponta para a planilha atual no Google Drive. A planilha é a fonte de verdade para preços e estado das compras; cópias JSON arquivadas não são sincronizadas.

## Arquivo

`arquivo/` contém diagramas, prompts e listas de planejamento antigos que ajudam a entender a evolução do projeto. Não representam decisões vigentes.
